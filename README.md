# Control Bionics Support Hub — V1.6

A static, no-API prototype of an interactive frontline support and knowledge hub.

## What is included
- Control Bionics logo in the header
- Product images for NeuroNode Duo, NeuroNode Trilogy, EyeGaze Duo, UNO Touch, Oskol 2 and NeuroStrip
- Interactive product support panels
- Quick fixes for common NeuroNode, Grid 3, Eye-Gaze and NeuroStrip issues
- Guided NeuroNode electrode / placement content
- NeuroStrip connection, patch, session, protocol, export and signal troubleshooting
- Official external resource links
- Microsoft Bookings support link
- Email escalation to Support.au@controlbionics.com
- Responsive layout for desktop, tablet and mobile
- No API, database or paid hosting requirement

## Run locally
Unzip the folder and open `index.html` in Chrome/Edge/Safari.

## Put online free with GitHub Pages
1. Create a new GitHub repository.
2. Upload the **contents** of this folder (not the outer ZIP).
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub to provide the public URL.

## Important
This is a proof-of-concept support site. Review and approve all product guidance internally before publishing it for customer use.
